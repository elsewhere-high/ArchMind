# 任务分派

1. 确认 Manager、Team、三个专业 Reviewer、协调者、核验者和 chief-engineer 人类身份可用。只使用当前任务授权的工作目录和输入。
2. 保存任务目标、输入副本和哈希；分配唯一任务 ID。审查者不得读取 expected-review-outline.md。
3. Manager 向协调者分派整体目标。协调者分别向三个专业 Reviewer 下发范围明确的任务。
4. 每位 Reviewer 先提取上下文，再格式化专业意见；保留实际技能使用记录和原始结果。协调者不能代写缺席专业的意见。
5. 协调者以两个以上专业的实际意见形成跨专业关系，再交给核验者检查来源、边界和待确认事项。
6. 核验后形成供人类阅读的预摘要，保存文件哈希及实际可获取的 Matrix 事件引用。文件存在不等于技能被实际调用。
7. Manager 检查完整性，把业务状态设为 WAITING_HUMAN，记录准确的未处理事项数量，向指定人类身份请求处置。
8. 按 [人工确认协议](human-gate.md) 等待真实决策。不得提前完成任务、关闭人工确认或伪造最终意见。

权限、路由或证据缺失时保留任务未完成状态并报告具体问题。凭据恢复、文件桥接等工程操作不能当作人类技术批准。
